# 작업허가 서류 검토

작업허가서에 첨부된 **작업계획서·위험성평가·특별안전보건교육** 서류를 넣으면
회사 점검 기준에 따라 누락·반려 사유와 서류 간 불일치를 점검하는 웹페이지입니다.

- 파일은 브라우저 안에서만 읽습니다(서버 전송·저장 없음). 서버 없이 정적 파일로 동작합니다.
- PDF(글자가 있는 PDF)·엑셀(xlsx)·Word(docx)·PowerPoint(pptx)를 읽고, 허가서·교육·기타 첨부 칸은 사진도 받습니다.
  스캔 이미지 PDF는 글자를 읽지 못하고, 옛 형식(.doc·.ppt)은 docx·pptx·PDF로 다시 저장해야 합니다.
  docx는 쪽 나눔, pptx는 슬라이드를 쪽으로 보고, 들어 있는 사진 수도 셉니다.
- **압축 파일(zip)** 은 넣는 즉시 풀어 안의 파일을 하나씩 넣습니다(압축 안의 압축은 2단계까지, 한국어 Windows의 CP949 이름도 판별).
  읽을 수 없는 파일(.hwp 등)·암호 걸린 파일은 건너뛰고 알려 줍니다. 특별교육 압축에 사진이 따로 들어 있으면 그 일지의 증빙사진으로 셉니다.
- 협력사마다 양식이 달라, 정해진 칸 대신 글자(파일 이름 포함)를 검색해 항목을 찾습니다.
- 결과 등급: **미흡(반려 사유)** / 확인 필요 / **직접 확인**(사진·서명처럼 사람이 봐야 하는 항목) / 적합 / 참고

## 작업허가서: Safe_B 화면 캡처

1. 작업허가서 칸의 **🖥 Safe_B 창 선택 캡처**를 누르고, 크롬 '공유할 화면 선택'에서 Safe_B 창을 고릅니다.
2. 찍힌 화면에서 허가서 부분을 드래그해 **넣기**(드래그하지 않으면 화면 전체). 여러 장 넣을 수 있습니다.
   Win+Shift+S로 찍은 뒤 이 화면에서 **Ctrl+V** 해도 들어갑니다.
3. 그림 속 글자는 브라우저 안에서 인식합니다(tesseract.js, 한국어). 표 테두리를 지우고 2~3배 키워 인식합니다.
   - 글자 인식은 **웹 주소(http/https)로 열었을 때만** 됩니다. 파일을 더블클릭해 연 화면에서는 브라우저가 막습니다.
   - 인식 결과는 결과 화면 아래 '서류에서 읽은 정보 보기'에서 확인할 수 있습니다.
4. 체크박스(☑/☐)·라디오(●/○)는 글자 인식으로는 구분되지 않아, **표시 테두리를 찾아 가운데가 채워졌는지**로 판단합니다
   (같은 묶음끼리 비교). 판단이 안 되면 '직접 확인'으로 표시합니다.

### Safe_B 화면 점검 (permit_form.js, 기준은 rules.js `permitForm`)
- 필수 입력: 작업명, 작업시작, 작업종료, 사업구분, 관리팀, 도급사, 작업장소 구분, 작업장소(사옥), 작업장소(세부), 작업내용, 작업책임자, 작업인원
- 필수 선택: High Risk **아니오**, 긴급작업 여부 **아니오**
- 작업구분 ↔ 서류
  - 화기작업 → 특별안전교육(화기·용접) / 가시설물 설치 → 달비계 특별교육 / 가시설물 해체 → 비계 특별교육
  - 전기작업 → 전기작업 계획서 / 건설기계(굴착기) → 차량계 건설기계 작업계획서
  - 건설기계(덤프트럭)·고소작업대(차량형)·고소작업대(시저형)·이동식 크레인·지게차 → 차량계 하역운반기계 작업계획서 **1쪽**에서 해당 장비(덤프트럭 / 고소작업차·스카이 / 고소작업대·리프트카 / 크레인 / 지게차) 체크
  - 반대로 서류(교육·계획서·1쪽 체크)에는 있는데 작업구분에서 빠진 작업도 알려 줍니다.
- 고르지 않은 작업구분 칸, 계획서의 체크하지 않은 장비(☐)는 작업·장비 판단에서 뺍니다.

## 점검 기준

### 작업계획서 (작성 대상이면 첨부 필수)
- 작성 대상: ① 차량계 건설기계(별표 6) ② 차량계 하역운반기계(지게차·고소작업대(차)·화물자동차·구내운반차)·중량물 취급(양중기, 체인블럭·윈치·레버블럭 등)
  ③ 깊이 2m 이상 굴착 ④ 50V 이상 전기작업
- 작성자·검토자 서명란, 도급사 안전관리총괄책임자·협력사 안전보건관리책임자 서명란(필수), 모든 서명란 서명(직접 확인)
- 작업지휘자 지정(필수), 계획서 안 한 페이지의 지정 내용
- 장비 사용: 신호수 지정(인력운반은 제외), 작업계획도(동선도), 장비별 자격서류(건설기계조종사면허·기중기운전기능사·지게차운전기능사/소형건설기계·고소작업대 조종교육)
- 중량물: 취급·결속방법(적절성은 직접 확인)
- 전기: 전기도면·단선도·결선도(실물 사진만이면 반려 — 직접 확인)

### 화기 작업
- 화기감시자 지정서(별도 파일), 화기감시자가 화기(화재위험) 특별교육 이수자인지

### 위험성평가
- 유해·위험요인, 감소대책, 담당·일정, 근로자 참여, 평가일, **위험도 상·중·하 표기**
- 작업계획서·특별교육의 작업이 모두 들어 있는지, 계획서 작업 내용이 반영됐는지

### 특별안전보건교육 (시행규칙 별표 5)
- 대상: 02 가스 용접·용단 / 14 1톤 이상 크레인 / 17 50V 이상 정전·활선 / 26 비계 / 34 밀폐공간 / 35 허가·관리대상 유해물질 / 38 화재위험작업(02 대체 가능)
- 작업별 교육일지 따로 등록(예: 화기+전기 → 2개)
- 교육시간: 정규 16시간(공통 8 + 작업 8) / 일용 2시간 + 일용직 채용 시 교육 1시간 서류 / 신규 정규 4시간 + 채용 시 교육 8시간 서류(3개월 내 12시간 추가) / 단기간·간헐 2시간(회사 기준 확인)
- 교육일(작업 전), 증빙사진 유무, 사진 확인 항목(당일 사진·시청각·복장·계절·인원수 — 직접 확인)

### 서류 간 일치
- 작업일과 계획 기간, 평가·교육이 작업 전인지, 허가서에 없는 작업, 작업자 ↔ 교육 이수자·평가 참여자

## 파일

| 파일 | 내용 |
|---|---|
| `index.html`, `style.css`, `app.js` | 화면 |
| `review.js` | 문서 읽기(PDF·엑셀·사진)와 검토 로직 |
| `rules.js` | **점검 기준**(작업 종류·키워드·필수 항목·법령 근거). 기준을 바꿀 때 이 파일만 고칩니다 |
| `lib/` | pdf.js 3.11.174, SheetJS 0.18.5, tesseract.js 5.1.1(+ core 5.1.1, 한국어·영어 4.0.0_best_int) 사본 |
| `samples/` | 체험용 가상 서류와 생성 스크립트. `scenario2/`는 전기+화기 시험 장면(주소 끝 `#demo2`), `office/`는 Word·PowerPoint 시험 장면(`#demo3`), `zip/`은 압축 시험 장면(`#demo4`) |

## 실행

- `index.html`을 더블클릭하면 바로 열립니다('샘플로 체험하기'는 웹 주소로 열었을 때만 동작).
- 웹으로 공개하려면 이 폴더를 GitHub Pages 등 정적 호스팅에 올리면 됩니다.

※ 글자 검색 기반의 보조 도구입니다. 내용의 적정성과 최종 판단은 검토자가 원문과 법령을 확인합니다.
