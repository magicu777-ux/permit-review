# 작업허가 서류 검토

작업허가서에 첨부된 **작업계획서·위험성평가·특별안전교육** 서류를 넣으면
필수 항목 누락과 서류 간 불일치를 점검하는 웹페이지입니다.

- 파일은 브라우저 안에서만 읽습니다(서버 전송·저장 없음). 서버 없이 정적 파일로 동작합니다.
- PDF(글자가 있는 PDF)와 엑셀(xlsx)을 읽습니다. 스캔 이미지 PDF는 읽지 못합니다.
- 협력사마다 양식이 달라, 정해진 칸 대신 글자를 검색해 항목을 찾습니다.

## 검토 내용

| 구분 | 점검 |
|---|---|
| 작업 정보 | 작업허가서(없으면 작업계획서)에서 작업 종류·작업일·작업자 |
| 작업계획서 | 공통 항목 + 작업 종류별 항목(밀폐공간·고소·전기·화기·굴착·양중·차량계) |
| 위험성평가 | 유해·위험요인, 위험성 결정, 감소대책, 담당·일정, 근로자 참여, 평가일, 허가 작업 포함 여부 |
| 특별안전교육 | 특별교육 명시, 교육시간(16시간/2시간), 교육일, 교육 대상 작업, 강사, 이수자 서명 |
| 서류 간 일치 | 작업일과 계획 기간, 평가·교육이 작업 전인지, 작업 종류, 작업자 ↔ 교육 이수자·평가 참여자 |

## 파일

| 파일 | 내용 |
|---|---|
| `index.html`, `style.css`, `app.js` | 화면 |
| `review.js` | 문서 읽기(PDF·엑셀 → 글자)와 검토 로직 |
| `rules.js` | **검토 기준**(작업 종류 키워드, 필수 항목, 법령 근거). 기준을 바꿀 때 이 파일만 고칩니다 |
| `lib/` | pdf.js 3.11.174, SheetJS 0.18.5 (오프라인 동작용 사본) |
| `samples/` | 체험용 가상 서류 4종과 생성 스크립트(`make_samples.py`) |

## 실행

- `index.html`을 더블클릭하면 바로 열립니다('샘플로 체험하기'는 웹 주소로 열었을 때만 동작).
- 웹으로 공개하려면 이 폴더를 GitHub Pages 등 정적 호스팅에 올리면 됩니다.

※ 글자 검색 기반의 보조 도구입니다. 내용의 적정성과 최종 판단은 검토자가 원문과 법령을 확인합니다.
